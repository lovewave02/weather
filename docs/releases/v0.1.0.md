# Weather v0.1.0

Release date: 2026-06-26

## Why this release exists

This first tagged release turns the repository into a clearer maintainer-run project instead of a code dump with silent drift.

## Highlights

- Added a contribution guide with backend, frontend, and automation verification commands
- Added issue templates for bug reports and feature requests
- Added a pull request template with validation and impact notes
- Added a release checklist and changelog discipline for future maintenance
- Added CODEOWNERS so maintainer ownership is visible in the repository
