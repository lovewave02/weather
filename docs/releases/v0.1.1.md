# Weather v0.1.1

Release date: 2026-06-28

## Why this release exists

`v0.1.1` turns the first public alert flow into a repeatable user-visible path
instead of leaving the final proof steps hidden in maintainer-only commands.

## Highlights

- Added reconnectable alert-user and saved-rule flows in the dashboard so a
  revisit user can continue where they left off
- Added disable/re-enable controls for saved alert rules instead of forcing a
  delete-and-recreate workflow
- Added a copy-paste quickstart and a repeatable smoke script so outsiders can
  try and verify the alert flow quickly
- Added manual dispatch proof for pending alerts in both the API smoke path and
  the dashboard, including visible `sentAt` delivery timestamps
- Tightened duplicate-create and invalid-coordinate error feedback so failed
  actions explain what went wrong
- Returned ingest run summaries in the API and surfaced them in the dashboard
  so operators can see what a manual refresh actually changed
